# qrMk — QR код генератор

Простая утилита для генерации QR кодов с кастомными цветами прямо из терминала.

## Запуск

```bash
python DoQr.py
```

Утилита спросит:
- ссылку или текст для QR
- имя выходного файла
- цвет точек в формате R,G,B (или Enter для красного по умолчанию)

## Пример
ссылка для QR: https://github.com/Roamal
имя файла: my_qr
цвет точек: 0,100,200

Результат: `my_qr.png`

## Зависимости

```bash
pip install qrcode pillow
```
